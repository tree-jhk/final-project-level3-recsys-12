# Technology choices

## Frontend: Svelte

<img src="https://user-images.githubusercontent.com/67851701/216808877-5262456f-e3f3-4673-aae0-8b04a0e634b2.png" width="100px" height="100px">

The team chose Svelte for compact, readable code and speed: “write less code,” avoid a virtual DOM, and move work into compilation rather than relying on a large runtime framework.

## Backend: FastAPI

<img src="https://user-images.githubusercontent.com/67851701/216809055-6e745f22-3f6f-438a-ad53-7f4c01daba40.png" width="100px" height="100px">

A Python-based framework aligned with the model code. The team valued performance, fast implementation, intuitive APIs and concise code.

## Database: MySQL

<img src="https://user-images.githubusercontent.com/67851701/216809436-be04e4d0-ec1b-402c-a778-bf9cf59245ad.png" width="100px" height="100px">

Relational storage with standard SQL suited the structured project data and efficient queries.

## Cloud: GCP

<img src="https://user-images.githubusercontent.com/67851701/216809494-01bc7465-a1b9-4fbd-ba12-9fe260f652f0.png" width="100px" height="100px">

At the time, the team considered the $300 trial credit, data services, reliability and scalability attractive. This is the **2023 selection rationale**, not a claim about current promotional terms.
