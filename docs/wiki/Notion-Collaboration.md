# Collaboration through Notion

The remote project made deliberate communication particularly important. The team used Notion as a shared workspace.

<img src="https://user-images.githubusercontent.com/67851701/217478247-5a08693f-b710-4aef-bd6e-e185a383e3e1.png" width="800">

**Workspace labels:** Project documents cover schedules, role allocation, plans, ideas, API specifications, environment setup, local execution, cloud deployment, Docker images and presentation materials. Other columns organize communication, conventions, troubleshooting and technical sharing.

## Technical sharing

Role specialization helped execution but could limit understanding of other components. Team members documented their own technologies so the whole team could learn. These notes were also published through [Tech Talks](Tech-Talks.md).

<img src="https://user-images.githubusercontent.com/67851701/217479437-f0a64025-cbd0-44d3-b427-ec45bc8b75d8.png" width="400">

**Technical-sharing topics:** Model improvement; technology-stack choices; databases; Airflow; GCP; sending Slack messages; product names as features; improving initial user-preference data; and object detection in interior images.

## Shared agreements

Five members had different coding styles, learning habits and perspectives. [Team conventions](Convention.md) provided common agreements for working as a coordinated team.

<img src="https://user-images.githubusercontent.com/67851701/217481227-e8c57fab-5eea-46dc-8aa4-1e33f379af2c.JPG" width="600">

**Workspace labels:** Settings include AIstage server access and terminal configuration. Shared conventions cover commits, branch naming, coding, W&B usage and naming, sweeps, GitHub collaboration and comments; project tracking covers labels, milestones, issues, pull requests, project boards and branch strategy.

## Small useful tips

Even a small discovery can be valuable to another teammate; practical tips were shared alongside larger technical explanations.

<img src="https://user-images.githubusercontent.com/67851701/217482705-95583e65-3c7f-4fd4-b56e-b355395af005.JPG" width="400">

**Tips menu translation:** Git command collection; Optuna usage; adding features to sequence models; useful Linux commands; handling `nohup`; useful VS Code extensions; Poetry usage; SQL trimming; and customizing the VS Code terminal.

## Scheduling

Notion tracked schedules and time commitments for organized development.

<img src="https://user-images.githubusercontent.com/67851701/217483592-156ebd44-4fa7-4235-9af8-84775524b45a.png" width="400">

**Task-board translation:** 'Part 2 — due Friday, February 3, 10:00.' Jisu Ryu and Youngseo Yoo owned deployment documentation and stabilization, marked completed with a January 29 deadline. Junhyuk Kwon owned data preprocessing: title-based item clustering, applying filters to all data, reprocessing CSV files and updating the database; its deadline was moved from January 29 to February 1. This is the historical assignment record, not a new task list.
