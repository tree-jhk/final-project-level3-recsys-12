# Team RAYN's commit convention

Consistent commit prefixes made changes easier for teammates to understand.

| Type | Meaning |
| --- | --- |
| Feat | New functionality |
| Fix | Bug fix |
| Test | Experimental functionality |
| Docs | Documentation |
| HOTFIX | Urgent fix |
| Style | Formatting with isort/black |
| Refactor | Code restructuring |
| Rename | File/directory rename |
| Remove | File removal |
| Chore | Other maintenance |
