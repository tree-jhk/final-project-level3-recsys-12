# Like buttons remained selected after refreshing recommendations

[Original issue #76](https://github.com/boostcampaitech4lv23recsys2/final-project-level3-recsys-12/issues/76)

After liking a product and requesting new recommendations, the product changed but its heart button remained selected. Debugging showed that the expected like-button component logic was not entered again.

The team tracked the component-refresh investigation and resolution in the linked issue. This wiki page did not include a standalone code fix; none is invented here.
