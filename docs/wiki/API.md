# API reference

Historical routes; the retired beta is not available as a live API.

| API | Description |
| --- | --- |
| `/home` | Main page for visitors who are not signed in |
| `/home/{member_email}` | Main page for a signed-in member |
| `/login` | Sign-in |
| `/card` | Interior photographs for signup |
| `/signup` | Signup |
| `/member` | Save a new member to the database |
| `/item/{item_id}` | Information for the specified item |
| `/mypage` | A member's liked products |
