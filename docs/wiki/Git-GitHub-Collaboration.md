# Collaboration through Git and GitHub

## Git

The team adopted [commit conventions](Git-Commit-Convention.md) and [Git Flow](Git-Flow.md) to improve communication, code management, consistency and conflict handling.

<img src="https://user-images.githubusercontent.com/67851701/217730239-d984b3cd-9915-452c-8894-28cda6f6e29f.png" width="200">

## GitHub

A shared PR template, labels and milestones made reviews easier to understand. Issues were not used extensively at first, but were used for important problems; see [project conventions](Project-Convention.md).

A project board shared development progress:

<img src="https://user-images.githubusercontent.com/67851701/217736193-80a6f064-8db5-42a9-9b45-8525c89f3b2f.png" width="600">

The team published a wiki to share lessons beyond the team. GitHub Actions was considered for CI/CD but **not implemented** because of the existing architecture. Docker, GitHub Actions and Airflow were considered for follow-up work; see [architecture redesign](Docker-Architecture.md).
